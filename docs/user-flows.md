# User Flows

## 1. Onboarding

1. User downloads the app / visits the web app.
2. User creates an account (email or social login).
3. User completes a short sleep-habits questionnaire.
4. App displays a personalised welcome dashboard.

## 2. Logging a Sleep Session

1. User taps "Log Sleep" on the home screen.
2. User enters sleep start time and wake-up time (or uses quick-log).
3. User optionally rates sleep quality (1–5) and adds notes.
4. App saves the entry and updates the dashboard.

## 3. Viewing Insights

1. User navigates to the "Insights" tab.
2. App displays charts for the past 7 / 30 / 90 days.
3. User taps a data point to see details for that night.

## 4. Receiving Recommendations

1. After sufficient data is collected (≥ 7 days), the app generates tips.
2. User receives an in-app notification or email digest.
3. User taps a recommendation to read the full explanation.

## 5. Setting Reminders

1. User opens "Settings" → "Reminders".
2. User sets a bedtime and/or wake-up reminder.
3. App schedules local push notifications accordingly.
