# Sleep Naked

> Better sleep starts tonight.

Sleep Naked is a wellness application that helps users improve their sleep quality through evidence-based tracking, personalized recommendations, and actionable insights.

## Repository Structure

```
sleepnaked/
├── README.md
├── LICENSE
├── CONTRIBUTING.md
├── docs/
│   ├── product-spec.md    # Product requirements and feature specification
│   ├── user-flows.md      # User journey diagrams and flow descriptions
│   ├── architecture.md    # Technical architecture and stack decisions
│   └── wireframes.md      # Screen wireframes and design annotations
├── app/
│   ├── mobile/            # React Native (Expo) mobile application
│   └── web/               # Next.js web application
├── backend/               # Node.js / Express API server
└── design/
    ├── assets/            # Icons, illustrations, logos, and image exports
    └── notes/             # UX research, design decisions, and brand guidelines
```
