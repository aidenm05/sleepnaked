# Contributing to sleepnaked

Thank you for your interest in contributing! Please follow the guidelines below.

## Getting Started

1. Fork the repository.
2. Create a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`.
3. Make your changes, following the coding standards below.
4. Commit your changes with clear, descriptive messages.
5. Push your branch and open a Pull Request.

## Coding Standards

- Write clear, self-documenting code.
- Keep pull requests focused and small.
- Include tests where applicable.
- Update documentation when changing behaviour.

## Reporting Issues

Open a GitHub Issue with a clear description of the bug or feature request, steps to reproduce (for bugs), and any relevant context.

## Code of Conduct

Be respectful and inclusive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/).
