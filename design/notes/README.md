# Design Notes

This directory contains design-related notes, decisions, and research for Sleep Naked.

## Contents

- UX research findings
- Design decision logs
- Accessibility considerations
- Brand guidelines and tone of voice
- Competitor analysis notes
- User interview summaries

## Naming Convention

Use descriptive filenames with dates for time-sensitive notes:

```
YYYY-MM-DD-topic.md
```

Example: `2024-01-15-color-palette-rationale.md`
