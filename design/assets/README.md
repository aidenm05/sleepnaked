# Design Assets

This directory will contain design assets for Sleep Naked, including:

- App icons (multiple resolutions)
- Splash screen graphics
- Illustrations and imagery used in the app
- Brand logo files (SVG, PNG)
- Color palette swatches
- Typography specimens
- Component design exports from Figma

## Usage

Organize assets by type:

```
assets/
├── icons/
├── illustrations/
├── logos/
└── screenshots/
```
